# Codex 表格处理

## 当前链路

WPS 侧栏选择范围并发送 → 本机桥接校验完整快照 → 当前对话对应的 Codex thread 追加 turn → 动态读取/统计/方案工具 → NDJSON 结果 → 侧栏预览 → 用户应用 → WPS 写入并回读。

每次发送都会重新采集范围，提交后使用不可变快照；用户之后切换工作簿不影响该次分析数据。
消息、回复、修改预览和应用结果都显示在同一个对话流中。一个侧栏对话对应一个 Agent 原生会话：连接时创建 thread，连续发送沿用同一个 App Server 和 thread，只追加 turn。上下文与历史压缩由 Codex 管理；插件不传 history，不截取或重放聊天。新对话先创建新的 Agent 会话，成功后关闭旧会话并清空显示；失败保留旧对话。恢复记录仍可使用。
每轮工具只绑定最新快照，旧范围不会授予新一轮写入权限。最近一次宿主操作反馈用于说明方案应用、放弃或恢复状态，供 Agent 在后续原生上下文中理解真实执行结果。
值、公式、格式写入和新增结果表由 WPS 宿主执行，Codex 的工具调用只生成方案；不具备任意文件、命令或原生图表操作工具。详细合同见 [表格操作规格](table-operations.md)。
Codex 使用 App Server 的实验性动态工具接口；WorkBuddy 使用单独的会话专用 MCP 表格接口，见 [WorkBuddy 接入](workbuddy.md)。

## 本机调用

- 从 PATH 或 `OFFICEBRIDGE_CODEX_PATH` 定位原生 Codex 可执行文件；Windows 可发现 VS Code OpenAI 扩展自带的可执行文件。
- `codex app-server --stdio`，不通过 shell 拼接命令。
- `initialize` → `initialized` → `account/read`，检查登录但不获取或保存令牌。
- `thread/start`：每个对话创建一次，`ephemeral: true`，独立空工作目录、`sandbox: read-only`、禁止审批升级。Agent 在进程内存保留本会话历史，不写表格聊天到项目文件。
- 本次进程禁用 shell、应用、插件、hooks、多 Agent、浏览器/桌面操作、技能发现和网络搜索，并清空本次 MCP 配置；文件写入由只读沙箱禁止。不修改用户全局配置。
- `turn/start`：使用用户原有默认模型。界面按钮触发后才会产生模型用量。
- 停止时请求 `turn/interrupt`，等待 `turn/completed` 后在原会话继续；1.5 秒内无法确认结束时关闭该进程并标记会话失效。新对话、侧栏关闭或服务退出才释放 App Server；Windows 仅终止该进程拥有的进程树。

会话失效不自动新建、不自动重发消息，需要用户明确开启新对话。本阶段会话只在内存保留，不支持跨进程重启恢复；侧栏卸载时尽力通知释放，桥接退出统一清理。最多同时保留 8 个侧栏会话，替换已有会话不占用额外长期名额。旧 `/api/v1/analyze` 继续使用一次性只读会话，不作为侧栏聊天入口。

会话与协议预检已使用本机 Codex `0.162.0-alpha.17.2` 验证。
动态工具接口会随 Codex 版本变化，升级后需要重新验证。

## 数据和工具

不再设置固定单元格数量上限，每次仍受 512 KB、50 个范围及宿主物理行列边界约束，包含值、公式和可读格式。范围可选当前选择、行、列、工作表或工作簿。读取按实际数据体积提前检查；超限、非连续选区、非法数值及超长单元格明确拒绝，不采样或截断。行列按 UsedRange 的对应维度裁剪，整表按 UsedRange 读取，可能包含残留格式。
提交给工具的数据不采样。单元格只作为数据，不能覆盖用户指令。

新版工具：

- `officebridge_list_ranges` / `officebridge_read_range`：范围元信息及完整快照。
- `officebridge_summarize_range`：精确分组统计，复用既有统计实现。
- `officebridge_inspect_range`：空值、整行重复、可识别的错误值，最多返回 100 个示例位置，同时返回完整计数。
- `officebridge_clean_range`：确定性去首尾空格和大小写整理，不覆盖公式。
- `officebridge_propose_edits`：范围内的值、公式和格式修改，生成方案，不执行。
- `officebridge_propose_result_sheet`：新增结果表方案，不覆盖同名表。

写入工具返回 `staged: true, applied: false`。只有本轮正常完成才发布 `proposal` 事件。侧栏应用前检查文件和原内容，写入后回读；最近一次变更可恢复，恢复前拒绝覆盖用户后续修改。公式只支持常见英文函数与当前表内引用。

旧 `/api/v1/analyze` 保留以下只读工具以兼容首版：

- `officebridge_read_selection`：读取本次完整快照。
- `officebridge_summarize_selection`：可选首行表头、最多三个分组列；统计各组记录数、各列空值数、数值数量、合计、平均值、最小值、最大值和前十个常见值。
- 分组最多 100 组；数字字符串保留文本语义，空值不作为零参与平均值。浮点运算遵循 JavaScript number 的精度限制。

桥接不把选区或原始模型回复写入项目文件或日志。模型服务与本地 Codex 的数据处理遵循其自身配置。

## HTTP 接口

| 路径                          | 方法 | 用途                                                                                  |
| ----------------------------- | ---- | ------------------------------------------------------------------------------------- |
| `/api/v1/session`             | GET  | 获取当前进程的随机请求令牌                                                            |
| `/api/v1/agents`              | GET  | 实际探测 Codex / WorkBuddy 接口可用性，其余适配器仍为计划状态                         |
| `/api/v1/analyze`             | POST | 接收 `{ prompt, selection }`，返回逐行 JSON 事件                                      |
| `/api/v1/conversations`       | POST | 接收 `{ id? }`，创建原生会话；可在创建成功后关闭要替换的旧 id                         |
| `/api/v1/conversations/close` | POST | 接收 `{ id }`，释放对应 Agent 会话                                                    |
| `/api/v1/run`                 | POST | 接收 `{ conversationId, prompt, workbook, operationFeedback? }`，返回分析与待应用方案 |

`conversationId` 必须由当前桥接创建；未知或已关闭的 id 返回 410。`history` 已移除，提交该字段会被拒绝；可选 `operationFeedback` 只传最近一次宿主操作状态，最多 4000 字符。

分析请求需同源 Origin、`application/json` 和 `X-OfficeBridge-Token`。
服务只监听 127.0.0.1，拒绝其他 Host 与 Origin，不提供跨域访问。
最多同时执行一次分析，超时两分钟自动停止；浏览器取消/关闭响应也会取消本次 Agent。
令牌仅在内存中保存，服务重启后需要刷新侧栏重新获取。

事件类型：`status`、`text`、`proposal`、`complete`、`error`。
仅 completed 且有回复内容或有效方案才完成任务；失败、空回复、取消、断连不会发布修改方案。完成推理与完成应用在 UI 中明确区分。

## 验证

自动测试覆盖数据完整性、分组统计、空值口径、协议状态、工具调用归属、错误、取消、超时、请求鉴权和未登录情况。
浏览器交互测试使用模拟 WPS 宿主与 Agent，验证数据发送、流式显示、取消、超限和无宿主状态。
本机真实预检只检查登录、会话创建、原生 thread 身份及关闭，不发送模型回合，因此不证明真实多轮模型回复的语义连续性。原生会话复用、快照更新、隔离、断连、取消和失败路径使用假 RPC 测试。

真实验收：在 WPS 选中含表头的机构/状态/时长数据 → 输入分组统计要求 → 点击发送 → 对照原始数据核对结果。
验收时应包含第 20 行以后的记录、空时长和失败状态，确认预览采样不影响统计。
新增验收：分别选择一格/行/列/工作表/工作簿，生成清洗/公式/格式/结果表方案，应用并回读，再恢复。切换文件、手工改动目标、合并或保护单元格必须拒绝错误应用。自动化通过不代表 WPS 实机或真实模型端到端通过。
