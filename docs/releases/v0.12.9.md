OfficeBridge v0.12.9 提供可直接下载的 WPS 加载项包。

- 保留豆包 Agent，侧栏名称改为“豆包”，去掉“（实验）”；已验证客户端为 Windows 2.32.6。
- WPS 加载入口命名为 `OfficeBridgeWPS.xll`，压缩包使用 `WPS/` 目录，便于与后续 Microsoft Excel 版本区分。
- 增加 GitHub Release 构建与发布流程：版本标签与源码版本一致，通过检查和独立打包验证后发布 ZIP 与 SHA-256 校验文件。

下载 `OfficeBridge-WPS-0.12.9.zip` 并完整解压，在 WPS 表格的 **工具 → 加载项 → 浏览** 中选择 `WPS/OfficeBridgeWPS.xll`，勾选并确定。请保留同目录的 `OfficeBridgeService.exe`、许可与使用说明，无需安装 Node.js/npm。不要使用 GitHub 自动生成的 Source code 压缩包代替发行包。

更新时先保存文档，在加载项管理中取消旧 XLL 后选择新版本。已有后台可能继续提供旧版资源；请先自行退出旧 OfficeBridge 后台，再使用新版本。

此包适用于 Windows x64 系统与 32 位 WPS 表格；Microsoft Excel 版本尚未包含。原生包和 GUI 后台使用独立测试宿主验证，不发送真实模型请求；WPS 实机冷启动、真实 Agent 操作与写入需按实际场景验收。本构建尚未配置代码签名。
