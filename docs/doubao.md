# 豆包 Windows 实验适配

## 调用方式

0.12.2 将连接准备集成到侧栏：选择豆包或重新连接时，先复用已开启的本机接口；未运行则自动启动；已运行但接口未开启时显示“重启并连接 / 取消”，确认后自动重启并完成只读验证，无需寻找脚本。仍区分端口不可访问、错误接口、主窗口缺失/重复、未登录和版本不兼容；不能把“进程正在运行”标记为已连接。GET 状态探测和桥接启动本身不会启动或终止客户端。

复用已经登录的 Windows 豆包客户端，通过仅本机 CDP 接口收发原生会话消息。默认连接 `http://127.0.0.1:9225`，可用 `OFFICEBRIDGE_DOUBAO_ENDPOINT` 指定其他本机端口。只接受 127.0.0.1，不连接普通浏览器或网页豆包，不改登录信息、快捷方式或豆包全局连接器配置。

侧栏连接时检查客户端页面、账号标识和运行能力，不发送模型消息。原生会话在首次发送时创建，后续消息必须使用相同 conversationId；新对话使用新绑定，首次发送创建新原生会话。历史保存在豆包，不由 OfficeBridge 拼接或重放；不会续接用户已有的其他对话。断连、账号变化、会话 ID 不一致或无法确认取消后要求新建对话，不自动重发。

## 表格操作

在 WPS 侧栏选择豆包即可。需要重启时先说明会中断豆包当前任务，等用户点击“重启并连接”；取消不关闭豆包、不清空草稿或原 Agent 对话。操作中显示连接进度，失败提供重试，失败不自动再次启动或发送模型消息。尚未登录时请在豆包客户端自行登录后重新连接。

`POST /api/v1/agents/doubao/connect` 受同源检查与侧栏令牌保护，不接受可执行路径、命令或端口。重启使用两分钟过期、一次性且绑定安装位置与主进程身份的确认凭据；执行前重新检查接口和进程，主进程被替换则重新确认，正常子进程变化无需再次确认。只终止已核对路径和启动时间的豆包进程，遇到其他接口、多安装目录或身份变化不接管；与分析和会话切换互斥。启动/重启后清理失效的豆包连接与续办凭据，已有豆包对话明确要求新建，不重放历史或静默新建原生会话。切换失败保留原 Agent 的会话。

启动从 Windows App Paths 和常见安装位置发现客户端，也接受开发者环境变量 `OFFICEBRIDGE_DOUBAO_PATH`；仅本次进程携带 `--remote-debugging-address=127.0.0.1` 和指定端口。开发诊断仍保留 `npm start -- --start-doubao` / `OfficeBridge.exe --start-doubao`，命令行入口不会终止运行中的客户端，便携包不再分发额外的启用脚本。

此版采用结构化请求协议，由 OfficeBridge 执行现有 17 个受限表格工具，包括行列增删、已有表改名、原表筛选和嵌入式图表，不宣称已接通豆包原生 MCP。每轮绑定最新快照和随机请求 ID，只执行通过校验的工具名称和参数；不接受模型直接返回可应用计划、脚本、命令或跨范围写入。普通文字可显示，但不能凭文字制造“应用”按钮。只有明确完成且本轮工具实际生成的方案才发布；失败、停止或超过交互上限丢弃方案。

一次用户任务使用一个随机 requestId，工具往返与格式纠正沿用该编号；下一次用户发送必须换号，即使复用原生会话也不接受上一任务的编号。编号不匹配的回复不执行工具，只允许在同一原生会话要求重新生成当前任务回复，不自动替换返回编号。

允许一个完整 JSON 对象或 JSON Markdown 代码块前后附带各不超过 200 字符的简短说明，说明可以用成对引号标注表名，但不能包含其他 JSON、跨越协议边界的引号、代码块或示例/引用标记。按字符串转义和括号配对提取唯一完整对象，继续校验协议、请求编号、工具和参数；多个对象、截断 JSON、引用示例或未知工具不能执行。内部协议不作为聊天内容展示。语法或编号错误每任务最多纠正两次，计入 8 次交互上限；不补传历史，不重发已执行工具，超过上限丢弃本轮方案。越界和不支持的工具仍直接拒绝。

用户仅要求新增并命名工作表时，工具使用 `values: [[""]]` 表示空表，不自动写入工作表名称、标题或示例数据。

一次用户发送可能包含多轮“请求工具—返回结果”，均追加到同一个豆包会话；每轮最多 8 次模型交互、32 次工具调用。只发送当前要求、当前范围与本轮工具结果，不补传侧栏聊天历史。修改继续由用户在 WPS 点击应用，沿用回读与恢复逻辑。

客户端协议请求固定使用云端任务环境，不配置本地文件共享、技能目录或本地 sandbox 路由。此设置用于让本地表格操作只经过 OfficeBridge 的校验；不表示离线推理，也不替代豆包账号自身的数据处理和权限规则。支持程度须以客户端实际响应和实机验收为准。

原生等待超时后，只按已确认属于本会话的 conversationId/runId 回读一次；只有该轮已完成且正文完整时才继续，不重新发送用户任务或执行残缺回复。未确认完成或其他传输失败时，在关闭连接前限时请求取消本轮任务；取消确认与否分别报告，连接标记失效并要求新对话，均不发布暂存方案。90 秒仍是原生等待预算，此修复不承诺消除客户端或服务端超时。

## 兼容与验收

0.12.2 验证（2026-10-22）：141 项自动测试、类型/格式检查、构建与版本目录 exe 独立启动检查通过。390/900 像素下共 18 个浏览器场景覆盖已就绪复用、未运行启动、重启确认/取消、确认过期、重启失败、未登录与重试、同一 Agent 旧连接失效及切换失败保留原 Agent/草稿；使用真实 HTTP 与连接管理模块，进程和 WPS 为测试替身。Windows 原生退出逻辑使用独立临时测试进程验证：错误启动时间拒绝终止，正确身份可退出，未关闭真实豆包。新 exe 的真实本机只读预检确认豆包就绪，集成连接接口返回复用已有客户端；未发送模型请求、未再次重启真实豆包、未修改用户表格。此记录不等同于用户 WPS 中重启及表格操作的完整实机闭环。

协议代码参考 MIT 许可的 doubao-cli，固定源提交并保留许可和修改说明。接收回复时保留流式正文；消息结束事件中的 brief 仅在没有正文时作为回退，不能用摘要覆盖完整工具请求。流结束后按本次原生 conversationId/runId 回读该轮已完成的完整回复，避免客户端增量流漏片段；不以摘要或残缺流作为工具请求，不重放历史、不读取其他用户会话。只纳入原生消息与任务状态所需模块，不调用其自动更新、凭证登录、磁盘会话记录、连接器注册或客户端启动代码。实现仍依赖非公开客户端行为，按实验能力提供。

分开报告：模拟客户端与受限工具测试；侧栏选择、连接错误、应用和恢复交互；本机只读预检；真实豆包与 WPS 闭环。自动测试不发送真实模型请求，不将模拟通过记为本机接入成功。尚未就绪的本机接口只报告不可用，不能通过“进程正在运行”标记已连接。

0.5.0 验证记录：47 项自动测试和 390/900 像素下的 14 个浏览器交互场景通过，覆盖连续会话、选择更新、应用与恢复、空表、取消和切换失败。原生协议通过虚构渲染器及实际打包器转换验证，未发送真实模型请求。本机只读预检返回接口未就绪，故不能宣称真实豆包已连接；2.32.6 实机推理与 WPS 端到端流程仍待验证。

0.5.1 实机验证（2026-10-20）：经用户授权，通过客户端菜单正常退出后以仅本机连接参数重新启动豆包 2.32.6，127.0.0.1:9225 已可连接。独立原生会话的两轮暗号测试验证了上下文保留。真实客户端测试定位并修复了 brief 摘要覆盖正文和增量流漏片段问题；最终适配器验收共发送 5 次真实模型请求，通过统计（10+20=30）、两格文本清理方案、刷新选区后一格清理方案、同一原生会话复用与新对话隔离。使用人工测试数据，源快照未改变，未操作用户 WPS 工作簿，也未将真实消息或会话编号保存到仓库。49 项自动测试通过；真实 WPS 中点击应用、回读和恢复仍待单独验收。

0.5.2 修复验证（2026-10-20）：处理工具 JSON 多余括号、完整 JSON 代码块和格式纠正失败的分支，内部协议不再作为普通聊天内容显示。51 项自动测试通过，包括同一会话中一次格式纠正、纠正失败不发布已暂存方案，以及模拟宿主的新建空表应用与恢复。使用真实桥接 HTTP 接口、真实豆包和独立人工快照发送“创建一个sheet，并且命名测试”，已返回名称为“测试”、内容为 `[[""]]` 的新增工作表方案，聊天文字不含内部协议。未在用户真实 WPS 工作簿上点击应用。

0.6.1 修复验证（2026-10-21）：针对 30 题测试暴露的问题，改为任务内固定随机编号、下一任务换号；编号错误不执行原工具，只允许有界纠正。兼容短说明加唯一完整 JSON，并拒绝多对象、引用示例、未知工具、越界参数和重复原生 runId。超时仅回读本轮已确认的原生任务，未完成则在断开前请求取消，准确区分取消确认与未确认。三个 Agent 共享不支持操作说明，避免自动替换用户要求。

62 项自动测试、类型和格式检查通过；构建、Windows exe 打包与无 Node 环境启动检查通过。超时后完整回复恢复、仍在运行/任务缺失拒绝、取消确认/未确认及失败不发布方案使用模拟客户端验证，本次真实复测未触发超时，不据此声称真实超时已消除。

真实豆包 2.32.6、真实桥接 HTTP 和模拟 WPS 复测 6 题，共 18 次模型请求：重复记录标记、按机构时长统计、机构汇总新表、反馈分类 4 题通过；写入方案通过项目实际宿主 JS 的模拟应用、回读和恢复。原表筛选、原生折线图 2 题明确说明尚不支持，没有发布替代修改方案；图表题同时通过统计说明趋势。分类中感谢类反馈沿用复核后的口径，允许“其他”或“待确认”。这不是全量 30 题重测，也不是实际 WPS 侧栏的应用/恢复验收；本轮没有改动用户真实工作簿。实测明细留在系统临时目录，不写入仓库。

0.7.0 功能验证（2026-10-21）：新增行增删、已有工作表改名、原生筛选和图表后，使用独立会话复测原 17/24/25/29 四题，共 14 次真实模型请求；四题均调用对应工具生成有效方案，经过模拟 WPS 的应用、回读和恢复。实际 WPS 原生 API 检查及浏览器交互验收范围见 [表格操作说明](table-operations.md)，不将此记录等同于真实 WPS 侧栏完整闭环。
