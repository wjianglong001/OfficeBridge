# 表格操作与 Agent 会话

## 范围与流程

0.12.7 单元格修改参数在进入宿主前预检：与最终快照校验复用同一组规则，返回 edits 下具体字段及修正说明，覆盖未登记范围、行列边界、未知字段、重复单元格、值/公式冲突、公式及格式无效。formula 必须以 = 开头，工具 schema 和各 Agent 共用指令明确这一要求；不替模型自动补等号或接受被禁止的公式。错误不读取宿主、不使读取任务失效，会清除之前暂存的方案和续办登记；WorkBuddy 与读取、图表参数共用每轮纠正上限，修正后的方案仍需用户应用。数据过期、真实宿主故障和取消保护保持原有语义。

0.12.6 图表 categoryOrder 只允许搭配 aggregation="sum"。此依赖错误在桥接层预检，不进入宿主、不使读取失效；Agent 可在同一轮选择省略排序参数以按原有汇总行序画普通图，或显式选择分组排序。不自动补参数或改写方案语义。与读取参数共用 WorkBuddy 每轮最多两次纠正的预算，第三次参数错误停止；真实宿主故障仍立即停止。已暂存方案在参数失败后清除，修正后的方案仍须用户应用。

0.12.5 超时按真实进展判断：不再把所有任务无条件截断在总计 120 秒。连续 120 秒没有新的正文、原生思考/工具参数进度或实际宿主读写往返则停止；每轮仍有 10 分钟总上限。WorkBuddy 的 agent_thought_chunk 仅转为节流的 activity 元信息，工具参数以增长或状态变化识别进展，重复状态标签/相同工具更新不能续期；不向侧栏或日志转发隐藏思考、参数正文或凭据。Stdio session/prompt 的有界兜底预算与总上限对齐，不再先于活跃任务在三分钟时截断。侧栏显示思考/准备操作，超时说明具体阶段，不再无依据要求缩小选区。用户停止、失败不发布方案、不自动重试，后续写入仍须应用。此调整修正桥接层的误中断，不承诺加快外部模型推理或消除服务端限制。

0.12.4 读取参数先在桥接层按本轮登记的完整范围校验，再进入宿主；不把 columns、rowOffset、rowCount、fields 的普通输入错误误判为宿主已失效。错误明确字段、允许下标与剩余行数，Agent 可在同一轮修正，不能猜测列字母/从 1 开始的列号、自动裁剪行数或扩大范围。WorkBuddy 每轮最多两次修正，第三次失败阻断 MCP 工具并请求取消，不发布方案。宿主读取、数据过期、越权或连接故障仍按原逻辑停止。read_range 返回 sourceRange 的完整尺寸，投影后的 rowCount/columnCount 与 columnIndices 只说明本次结果；省略 rowCount 读取 rowOffset 后的剩余行。

0.12.3 修正 WorkBuddy 限制说明：`quota` / `14003` / HTTP 429 仅说明服务端拒绝该次请求，不据此判断用户积分耗尽或桌面端余额。只展示已知状态和固定服务码，不展示原始响应或凭据。宿主按需工具出错会使本轮读取失效：先返回首次工具错误，再停止本轮和请求取消 Agent，避免模型继续使用失效范围；侧栏显示实际的图表/表格错误，自动续办失败保留上一步已应用结果，后续仍须用户主动发送。不能将本修复等同于已查明任意 WPS 图表故障根因。

0.12.2 豆包连接准备已集成到侧栏：选择豆包时检查接口，未运行则启动；运行中但接口未开启时展示“重启并连接 / 取消”，确认后自动重启并验证，不再要求单独寻找脚本。切换失败保留原 Agent 和草稿；取消、失败不自动重试。启动或尝试重启导致旧豆包绑定失效时，清理绑定及续办凭据并明确要求新建对话，不伪装已连接或重放历史。GET 状态查询不启动或终止客户端，详见 [豆包适配](doubao.md)。

0.12.1 WorkBuddy 失败分类：解析 ACP 完成结果 errorMessage 或 `_meta["codebuddy.ai/errorMessage"]` 中的结构化状态，分别显示额度/用量、429 限制、认证、权限、内容拒绝、输出长度及轮次上限。不直接展示原始响应、URL、凭据或用户数据；停止及失败不发布暂存方案，不自动重试/新建会话。自动续办失败明确保留上一步已应用的结果；服务端额度限制不能当作本地工具故障或通过自动重试绕过。

0.12.0 统一后台执行器：所有主动表格操作（发送选区、按需查询、统计检查、清洗与方案生成、应用、恢复）都通过 executor 的串行任务队列，聊天层不直接调用宿主执行方法。统计、检查、清洗、方案合并/校验和图表精确计算使用同源 Web Worker；任务用消息回传，停止时终止 Worker，拒绝迟到结果。WPS 适配器负责接口访问，长读取、来源检查与结构恢复基线分段执行；提交前重新核对，原生修改、回读及回滚保持一个同步事务，不能把同步宿主调用宣称为独立进程或可随时中断。被动选区/连接/恢复状态为轻量元信息查询。后台线程不可用时明确报错，不静默回退到界面做重计算。执行中的新消息可先写草稿，提交仍串行，避免同文件并发写入。恢复同样经统一队列；现有宿主恢复事务仍同步执行。

0.12.0 图表应用性能：新增图表使用独立事务，只保留源数据/公式、已读取参考数据和目标表图表集合，不再为图表捕获整本工作簿格式、行高、列宽或无关表数据。应用前/后仍核对来源和图表，失败只撤销本次新增图表，恢复不覆盖单元格。值优先按连续块批量核对；宿主不支持矩阵读取时回退逐格读取。应用前的较长检查分段让出界面，可停止且不写入；提交前最后一次核对及原生图表创建/回读保持同步，防止检查与写入之间被改动。原生宿主调用本身不可中断，不承诺其耗时上限。批量配置图表期间暂缓屏幕重绘，并恢复原设置。用户可继续输入草稿；应用和续办仍串行，停止、失败不自动继续。图表恢复不因无关表的格式变化而被阻止，源数据/公式、引用、工作表结构或图表被编辑则拒绝覆盖。

0.11.0 多步骤续办：Agent 完成本轮修改方案后，如果用户原任务尚有后续步骤，调用 `officebridge_continue_after_apply(nextStep)` 明确登记下一步。仅已生成有效方案时可登记；单步任务不登记，不从普通回复文字猜测。成功结束本轮后桥接服务为方案签发一次性续办凭据，绑定当前原生会话、工作簿及快照。侧栏点击应用成功后，立即带真实宿主执行结果与新的按需描述追加同一 Agent 会话；后续修改仍只能生成预览，必须再次应用。自动轮次只传新描述、不预读当前光标数据，不消耗或覆盖用户草稿，不伪造“继续”用户气泡。聊天历史由 Agent 管理，桥接层只保存待应用步骤和短期凭据。

应用失败/不确定、放弃、停止、恢复、新对话、切换 Agent/文件、新的人类指令均不自动继续旧步骤；自动请求失败不重发、不另建会话。应用中的停止只能禁止后续续办，不能中断已进入的同步宿主写入。每个方案只续办一次，凭据 30 分钟过期，重复/过期/跨会话/跨文件凭据拒绝；原始已应用快照不得当作新描述提交。每条自动链最多 8 轮，达到上限后保留预览并明确暂停。提问或工具失败清除续办标记，只有完整成功的 turn 才发布续办方案。建表后绘图仍是两次预览/应用，但中间无需用户再输入“继续”。

0.10.0 修正交互：侧栏取消范围模式、下拉和锁定。左下角仅展示实时选区（没有单元格选区时显示当前工作表），发送时固定本轮文件/选择，并附带完整选区值。空白选区不附带数据，默认光标不限制任务。采用 `navigation.mode="context"` 和 `selectionProvided` 标记：Agent 先判断已提供数据是否足以完成问题，够用直接分析/生成方案，不够再复用定位、读取和统计工具。选区是上下文与用户指代对象，不是禁止补充读取的权限边界；用户明确要求只修改这些行时，Agent 必须保持该写入目标。公式/格式仍按需读取。当前工作簿内可按任务补充跨表数据，不访问其他文件；修改仍预览并应用前核对所有已读来源。

完整选区不再受 16 格内联限制；仍受 512 KB 实际数据体积预算，使用值的矩阵分块读取，不读取格式或恢复基线。超限明确报错，不抽样、不截断、不伪称已附带。没有选区时不预读内容，由 Agent 决定定位与取数。旧自动/锁定协议仅兼容旧客户端，不出现在新侧栏中。发送期间移动选择不重定向本轮任务；完成后左下角继续跟随实时选择。

兼容旧版（当前侧栏不适用）：0.9.0 默认使用“自动判断范围”，当前光标/框选仅作为指向线索。发送仍只准备描述，Agent 在同一原生会话内用 `officebridge_resolve_range` 定位，再复用已有按需读取、统计与修改工具。默认只可定位当前工作表；用户指令明确提及的工作表和明确的整个工作簿请求才允许跨表，宿主据本轮原始指令生成允许列表，不接受模型自行扩大。结构、范围定位结果和实际数据均为数据，不是指令。自动模式不自动执行写入。

范围工具支持固定选区、光标周边连续区域、当前表已用范围、指定行列矩形，以及上一轮已定位范围。连续区域是候选范围，不能假定其就是完整业务表；宿主不支持连续区域时返回已用边界并标明需要检查。Agent 按需读取表头和相关列，存在多张候选表、金额口径不明或数据不足时调用 `officebridge_ask_user`，提供 2–3 个简短选项；本轮结束后在聊天中显示按钮，点击自动追加原生会话消息，无需重写原题。提问后禁止在同轮发布修改方案。模型不得把表格内容当作用户授权，不推断跨工作簿权限。

“锁定当前选区”在点击时固定文件、工作表和矩形，后续移动光标不重定向；读取和修改均不得越界。解除锁定恢复自动模式，新对话/切换 Agent 默认自动且清除范围延续信息。自动模式只有在文件及指向位置未变时提供上一轮范围作参考，仍需本轮重新定位/读取；历史范围 ID 不得复用。运行期间的光标移动不改变已发任务；应用前保留内容和文件核对。只有本轮定位成功的范围能被读写，修改预览分别显示参考数据与实际修改对象。

自动模式允许同一工作表登记多个读取区域，但同一轮同一工作表的写入快照仅支持一个区域；需要多区域修改时明确拆分，不能合并成包含未请求单元格的大矩形。旧完整快照与明确范围 API 保持兼容。自动定位不取消 512 KB、50 个范围、每轮 32 次宿主工具等限制。

按需通道（0.8.0）：侧栏默认先发送 `readMode: "on-demand"` 的工作簿描述，只包含文件身份、范围边界、表名和能力元信息，不预读工作簿内容及恢复基线。最多 16 格的小选区可携带真实值，便于直接回答简单问题。锁定/兼容任务以固定选区为边界，自动任务以本轮允许的工作表和已定位范围为边界，运行期间不随光标移动改变。

本地 NDJSON 流中的 `host_request` 和受同源 token 保护的 `/api/v1/host-result` 组成双向请求通道；每次调用绑定本轮随机 ID、快照 ID 和调用 ID，有超时、取消和迟到回复拒绝。三种 Agent 共用异步工具代理；模型不获得文件系统、宏或任意脚本执行权限。旧完整快照接口保留兼容，不作为侧栏默认发送流程。

读取工具可指定行偏移、行数、列索引和字段，默认只读值；统计工具在宿主按相关列执行并只回传统计结果。重复读取仅使用本轮内存缓存，再次查询前核对已读内容，发现变化则要求重新发送；不缓存或重放 Agent 聊天上下文，不用样例代替全量统计。普通提问不准备结构恢复基线。只有真正调用修改工具时才捕获对应范围的写入基线；结构操作仅准备所需的一种完整恢复基线，不再无条件扫描三类基线。准备前核对本轮已读数据，预览后的应用/恢复仍核对完整基线，失败/取消后不发布方案。

验收单独测量描述准备、HTTP 接收和首条实际文本；“正在处理”不计为 Agent 回复。单格提问不得读取其他单元格或未选工作表的 UsedRange；无读取需求的消息不得触发数据扫描；按列查询不得读取其他列的值、公式或格式。大范围计算仍按实际数据量执行，不承诺所有模型推理或大表计算均在一秒内完成。

当前支持 Codex App Server 和 WorkBuddy 桌面包 ACP，复用相同的表格工具。系统是混合型：自然语言理解由所选 Agent 完成，范围解析、参数校验、修改、回读与恢复是确定性操作。WorkBuddy 的接口和运行时约定见 [接入说明](workbuddy.md)。

新增豆包 Windows 实验适配，见 [豆包接入说明](doubao.md)。豆包通过原生云端会话收发结构化工具请求，再由 OfficeBridge 校验执行同一套表格工具，不冒充已接入豆包原生 MCP。连接时只读预检，首次发送才创建原生会话；后续复用原生 ID。原生接口、账号、会话不匹配或取消无法确认时要求新对话，不自动重发。豆包真实模型和 WPS 端到端验证仍单独报告。

侧栏默认自动判断范围，也可锁定当前选区；兼容接口仍支持选择、行、列、工作表和工作簿范围。不需要读取按钮。锁定选区不自动扩大；整行整列及行列模式按工作表 UsedRange 的相应维度裁剪。整个工作簿用各 Worksheet 的 UsedRange 确定边界，内容仍按需读取。取消固定 5000 单元格数量上限，读取、修改方案、新结果表和完整恢复基线均按实际数据体积校验，仍保留 512 KB、最多 50 个范围及宿主物理行列边界。读取时增量累计序列化数据大小，超过体积预算提前停止；最终仍核对完整 JSON 大小。超限清楚报错，不采样、不截断，不静默退回部分数据。UsedRange 可能包括残留格式，不能视为绝对的数据边界。

选区摘要只读取元信息。发送时固定本轮授权描述，工具调用时才读取相关值、公式或格式。每次任务绑定 connectionId、snapshotId、文件完整名称、工作表名称和绝对行列。UI 切换选区不改变本轮边界，切换文件或已读数据变化时拒绝继续。

发送准备先显示用户消息和“正在读取表格”，立即进入忙碌状态，给浏览器绘制机会后才执行同步宿主读取。读取前固定本次文件及范围元信息，绘制等待期间范围/文件变化则拒绝本次发送，不读取新选区替代旧目标。读取结束后再次让出界面，检查取消再发给 Agent；读取失败或发送前取消明确标记消息未发送，输入为空时恢复原草稿，不覆盖期间新输入。重复点击、回车、切换范围/Agent 和恢复操作沿用同一忙碌锁。

按需读取默认仅包含值，允许指定 `columns`（原范围零基列号）、`rowOffset`、`rowCount`、`fields`；统计允许指定统计列、分组列及严格数字文本转换，只回传统计结果。相邻请求列采用最多 256 格的块读取；不跨越未请求列，宿主不支持矩阵时回退逐格读取。每轮读取缓存累计按 512 KB 检查、最多 32 次工具调用，单次宿主等待最长 30 秒。写入时才读取相关范围的真实值、公式和格式；不以占位值伪造快照。旧同步完整捕获仍保留兼容，缓存只在单次捕获内复用，与私有恢复基线隔离。缓存不跨任务、不替代应用/恢复前的核对；整行、整列及图表操作的完整恢复检查保持不变。

## 工具与修改

汇总图表：`officebridge_create_chart` 可选 `aggregation: "sum"`，按分类列分组求和，`categoryOrder: "ascending"` 按分类升序（数字按数值，文本按字符；规范 YYYY-MM 月份按时间排列），省略则按首次出现顺序。只对本轮选区计算，首行为表头。分类文本去除首尾空白，金额允许有限数值或严格十进制数字文本（含规范千分位、首尾空白和前导单引号），不猜测货币、百分比或单位。完全空白的图表数据行计数后略过；有分类但金额缺失、无分类但有金额、非数值、混合分类类型和明显合计分类均明确拒绝，不静默补零或丢弃异常行。十进制精确求和，超过宿主 15 位有效数字或系列公式容量时拒绝。

分组值由桥接层根据快照确定性计算，模型只指定列及规则；共享计算用于校验、工具结果、侧栏预览与宿主执行。预览显示汇总数据、明细行数和格式转换数量。应用后在源表创建原生图表，以图表内的常量数组保存本次汇总快照，不改写源数据、不添加辅助工作表；明确提示源数据后续变化须重新生成。CSV 文件的图表预览提示另存为 .xlsx 才能保留图表，不自动保存或转换原文件。取消、失败、过期状态及恢复沿用图表事务保护。普通图表继续引用原选区数值单元格，不自动汇总；三种 Agent 共用此能力。

新任务端点 `/api/v1/run` 接收按需描述或兼容完整快照，旧 `/api/v1/analyze` 保持只读兼容。提供范围读取、精确分组统计、数据质量检查、生成修改方案工具。宿主返回的写入快照在桥接层验证范围后仅用于修改方案，工具调用只把 `result` 交给模型。修改方案包含值、公式及数字格式、加粗、填色；只能修改选定范围。支持在当前工作簿新增结果工作表，不能覆盖同名工作表。

三个 Agent 共用能力说明，新增整行插入/删除、现有工作表改名、原表筛选和嵌入式图表工具。原生排序暂未实现，普通无公式值表仍可在完整选区内重排。不得擅自用新表、清空内容或覆盖数据代替用户要求的操作。

行操作使用 `rowChanges: [{rangeId, action, row, count, values?}]`，row 为范围内从 0 开始的偏移，单次一块连续 1–100 行；插入可在范围末尾追加，删除只能包含选中行，影响这些行的所有列。values 仅用于插入，形状为 count × 选区列数，从选区起始列填写。沿用完整工作簿受限恢复基线，另保存行高、隐藏状态；拒绝复杂结构、多工作簿、过期基线和引入新公式错误的操作。

工作表操作使用单个 `sheetActions` 项，与行列操作、单元格修改、新表互斥。`rename` 只改 rangeId 所在表，名称须合法、与现有名称大小写无关地不冲突，原生更新引用；`filter` 将选区首行作为表头，条件为至多 3 个不同列的 AND 条件（eq/ne/gt/gte/lt/lte/contains），不删除或改写值，空条件清除该范围筛选；已有其他范围筛选时拒绝替换。`chart` 以选区首行为表头，指定分类列及 1–3 个数值列（饼图仅一列），在源表新建折线/柱形/条形/饼图；普通图表只引用选区内单元格，分组图表只使用选区内本地计算的汇总常量，不执行任意公式、脚本或外部数据引用。

快照中的 rowOperations 和 sheetOperations 返回本次宿主可用性及原因。预览必须显示工作表、绝对行号/表名变化/筛选条件/图表源范围。应用前与恢复前对有界完整工作簿状态进行核对；图表核对名称、位置、大小、类型、标题、系列和可读取的常见外观属性，拒绝覆盖这些属性的后续编辑。高级筛选（颜色/图标/动态日期）、复杂命名区域、保护及不可完整读取的宿主状态明确拒绝。失败尝试恢复并回读，无法确认恢复则禁用自动恢复并报告；不自动保存。

新增 `officebridge_insert_columns` / `officebridge_delete_columns`，执行 WPS 原生整列插入/删除。column 为所选 range 内从 0 开始的位置：插入发生在该位置之前，等于 columnCount 表示追加到选区右侧；删除只能覆盖所选范围包含的列。单次处理一块连续的 1–20 列，不与普通单元格修改或新建工作表混合；多步骤任务应用后再继续。插入可附带与选区行数一致的二维 values，填写表头和数据；省略表示空列。整列移动影响工作表所有行，预览必须显示工作表、绝对列位置和列数，删除提示整列数据将被移除。

列操作捕获整份工作簿的有界恢复基线，仅保存在宿主内存，不交给 Agent 扩大读取范围。基线不再按单元格数量拒绝，仍保留 512 KB 体积预算，包含值、公式、单元格格式、列宽及隐藏状态；结构复杂（保护、合并/数组公式、表格/透视表、图形、命名区域或单元格批注/验证等）的工作簿先拒绝列操作，普通单元格工具不受影响。快照提供列操作可用性和原因。应用前核对基线及文件身份，插入后核对原数据移位与新增值；删除引入新的公式错误时回滚。插入后完整状态超出体积预算时回滚，不发布成功。恢复先检查整个基线没有后续编辑，再执行反向列操作并恢复原内容、公式及格式。无法确认原生调用是否部分执行或恢复不完整时，明确报告并禁用自动恢复。不会自动保存文件。

部分 WPS 版本对隐藏列返回列宽 0；插入时保留并由原生反向操作恢复已有隐藏列，不用 0 覆盖其实际列宽。若删除目标包含无法读取实际列宽的隐藏列，则在修改前提示先取消隐藏，避免删除后无法恢复原宽度。

此版列操作仅在打开一个工作簿时启用，避免 WPS 自动改写其他打开文件中的引用而无法完整恢复；单个工作簿可以包含多张表，表内及表间公式引用按同一基线核对和恢复。

模型工具成功仅表示修改已加入方案，不表示已经执行。只有 Agent 任务正常完成后才发布方案；中断或失败丢弃方案。用户检查方案后点击消息下方的“应用”，WPS 宿主执行并回读验证。普通分析没有额外确认步骤。

应用前核对当前文件身份、原内容、目标边界、保护及合并单元格状态；目标变化拒绝应用。禁止任意脚本、系统命令、宏和外部数据公式；本轮公式仅支持经过校验的常见函数与当前表内引用。保持 Agent 本身的文件沙箱只读，所有表格修改由受限宿主接口执行。

修改前在内存保留值、公式和本次涉及的格式，应用失败尝试恢复。保留最近一次成功应用记录；“恢复本次修改”先核对目标仍为本次应用后的状态，避免覆盖用户后续编辑。新增结果工作表仅在内容未被改动时才可恢复删除。关闭侧栏后恢复记录丢失；不写磁盘、不自动保存工作簿、不宣称宿主原生 Ctrl+Z 可用。

空单元格兼容：无公式单元格的 `null`、`undefined` 和空字符串按空内容归一校验；数值 0、布尔 false、数字字符串及产生空文本的公式仍严格区分。新增工作表的空占位单元格不重复写值，仍回读确认其为空；清空已有单元格优先使用 ClearContents，保留格式。捕获、应用、失败恢复和撤销采用一致的空值语义。
